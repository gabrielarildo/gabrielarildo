## 🚀 Projetos e experiências práticas

### 📋 Checklist de Avaliação e Treinamentos

Aplicação mobile desenvolvida para facilitar o preenchimento de checklists de avaliação e treinamento, com geração de documentos PDF e compartilhamento dos arquivos.

- Formulário dividido em etapas.
- Geração e compartilhamento de PDFs.
- Armazenamento local de dados.
- Desenvolvimento com foco em organização e usabilidade.

**Tecnologias:** React Native · TypeScript · Expo · AsyncStorage

🔒 Código-fonte privado.

### 🐾 PET 24H

Projeto colaborativo desenvolvido durante um hackathon acadêmico, com a proposta de facilitar a divulgação de animais perdidos e encontrados.

- Identificação por QR Code.
- Consulta a informações de identificação dos animais.
- Aplicação web com foco em acessibilidade e conectividade.
- Proposta de aplicação como Progressive Web App.

**Tecnologias:** React · TypeScript · Vite · Tailwind CSS · Supabase · QR Code · Mapas · PWA

🤝 Projeto desenvolvido em equipe. Repositório não publicado no GitHub.

### 🍽️ Conveniência Cruzado

Sistema web desenvolvido com ASP.NET Core MVC, voltado à implementação de funcionalidades de uma conveniência e à aplicação de conceitos de desenvolvimento de sistemas.

- Organização da aplicação utilizando arquitetura MVC.
- Desenvolvimento com C# e .NET.
- Persistência de dados com Entity Framework Core.
- Prática de organização e estruturação de código.

**Tecnologias:** C# · ASP.NET Core MVC · Entity Framework Core · .NET 10

🔒 Repositório privado.
